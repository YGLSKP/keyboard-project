보상기준 3

이 문서의 모든 설계는 아래 세 전제에서 파생됩니다.
개별 기능 판단이 애매할 때는 여기로 돌아와 판정하십시오.

PRINCIPLE 01

확정성

  • 사용자가 통제 가능한 행동만으로 보상 100% 보장
  • 확률·선착순·타인의 행동이 개입이 가능하면 적은 방향
PRINCIPLE 02

즉시성

  • 적립은 즉시 잔액에 반영
  • 가능한한 빠른 정산, 지연 있을 경우 반드시 표기
PRINCIPLE 03

투명성

  • 행동 이전에 금액·지급시점 공개
  • 모호한 문구 지양

Chapter 5 · Risks & Validation
5. 검증이 필요한 가정과 리스크

다음 단계 · 데이터로 검증할 것

이 문서의 퍼소나는 가설 단계입니다.
아래 실데이터로 3개 군집이 실제 존재하는지 검증한 뒤 확정하십시오.

5.1 퍼소나 가설 검증 지표

  • 세션당 체류시간 분포 — 3개 군집으로 실제 갈리는가?
  • 광고 시청 완료율 — 퍼소나별 편차 확인
  • 출금 전환율 및 주기 — 잔액 임계값 검증

5.2 세그먼트 확장 시 주의

이 판단 기준은 확정 선호 · 시성비 중심 · 40-50대 퍼소나를 전제로 합니다.

20-30대 확장을 검토한다면, 판단 기준 자체를 세그먼트별로 분리해 관리하는 편이 안전합니다.
